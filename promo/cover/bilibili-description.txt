【净广告 SkipAd】一款不用 Root 的 Android 去广告工具，纯 Kotlin 实现，开源免费。

40 秒看懂它怎么工作：DNS 引擎让广告域名解析失败，无障碍引擎识别「跳过」并自动点击。两条路线互补，覆盖单一方案的盲区。

协议：GPL-3.0，完全免费，无广告、无内购、无需登录，不收集使用数据

▍怎么用
Android 8.0（API 26）及以上，无需 Root
① 安装后允许 VPN 授权 ②「规则源」页更新规则 ③ 主页开启保护 ④「应用」页开启无障碍服务（跳过开屏广告需要）
国产 ROM 建议顺手做三件事：最近任务里锁定后台 + 允许后台运行 + 允许自启动，避免一键清理把服务一起关掉。

▍如实说明的局限
· 只拦 DNS 层，同一域名下的路径型广告（如 /banner.jpg）拦不住
· 系统开启「私人 DNS（DoT）」时，部分机型可能绕过本应用的 DNS 代理
· Debug 包与 Release 包签名不同，装过旧版请先卸载再安装

三级规则索引、拦截日志与按应用统计、自定义域名回读确认、六层保活自检，204 项单元测试全部通过。欢迎 Star、提 Issue 和 PR，也欢迎在评论区告诉我还有哪类广告没拦住。
